| 参数 | 说明 | 类型 | 可选值 | 默认值 | 适用渠道 | 备注 |
| ----- | :-------- | ---- | ---- | ---- | ---- | :---- |
span|栅格占据的列数|number|||w,m,s||
offset|栅格左侧的间隔格数|number||0|w,m,s||
push|栅格向右移动格数|number||0|w,m,s||
pull|栅格向左移动格数|number||0|w,m,s||
sm|≥768px 响应式栅格数或者栅格属性对象|number/object (例如： {span: 4, offset: 4})|||w,m,s||
order|flex的order属性|string|||w,m,s||
background|col列的背景颜色|string|可取任意颜色值||w,m,s||
