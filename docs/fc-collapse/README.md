# fc-collapse 折叠面板

## 属性

| 参数 | 说明 | 类型 | 可选值 | 默认值 | 适用渠道 | 备注 |
| ----- | :-------- | ---- | ---- | ---- | ---- | :---- |
accordion|是否手风琴模式|boolean||false|w||
options|折叠面板条目|Array|||||

## options属性

| 参数 | 说明 | 类型 | 可选值 | 默认值 | 适用渠道 | 备注 |
| ----- | :-------- | ---- | ---- | ---- | ---- | :---- |
name|唯一标志符|string/number|||w||
title|面板标题|string|||w||
value|是否展开|boolean||false|m||
hide-on-blur|点击遮罩时是否自动关闭|boolean||true|m||

## 事件

| 事件名称 | 说明 | 回调参数 | 适用渠道 | 备注 |
| ------ | :-------- | :---- | ---- | :---- |
change|当前激活面板改变时触发(如果是手风琴模式，参数 activeNames 类型为string，否则为array)|(activeNames: array|string)|w||
